# UNP_ML_CLASSIFICATION_PROJECT_CREDIT_CARD_APPROVAL_USING_PYTHON

This project was completed as part of the **United Network of Professionals (UNP) Machine Learning Academic Internship Program**.

The project focuses on predicting credit card application approvals using machine learning techniques. It aims to develop a reliable classification model by analyzing applicant information and identifying patterns that influence credit approval decisions.

### Project Overview
- Worked with a dataset containing 690 credit card applications and 15 input features.
- Performed exploratory data analysis (EDA) to understand relationships between applicant attributes and approval outcomes.
- Identified data quality issues and applied appropriate preprocessing techniques.
- Conducted feature engineering, categorical encoding, and feature scaling to prepare the dataset for modeling.

### Machine Learning Implementation
- Developed classification models using Logistic Regression, K-Nearest Neighbors, Decision Tree, and Random Forest.
- Implemented advanced algorithms, including XGBoost, Support Vector Machine, and Gaussian Naive Bayes.
- Explored Artificial Neural Networks (ANN) using TensorFlow for predictive modeling.
- Evaluated model performance across different training and testing splits.
- Applied cross-validation and hyperparameter tuning to improve model reliability.

### Model Evaluation
- Compared classification models using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
- Analyzed confusion matrices to understand prediction errors and classification performance.
- Examined the effectiveness of different algorithms in predicting approval outcomes.

### Project Outcome
The project provided practical experience in data preprocessing, exploratory analysis, classification algorithms, neural networks, and model evaluation. It demonstrates an end-to-end machine learning workflow for credit card approval prediction while highlighting the importance of selecting appropriate models for financial classification problems.
